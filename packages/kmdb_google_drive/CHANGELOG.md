# Changelog

## 0.1.0

First stable release, published to pub.dev. Targets `kmdb` `^0.1.0`.

Provides `GoogleDriveAdapter`, an optional `SyncStorageAdapter`
implementation backed by Google Drive. Carries the authenticated sync-artefact
format introduced in `kmdb` 0.1.0 (adapters transport the sync-auth envelope
unchanged). See the `kmdb` `0.1.0` changelog for the underlying sync changes.

### Requirements

- Dart SDK `^3.13.0`.
