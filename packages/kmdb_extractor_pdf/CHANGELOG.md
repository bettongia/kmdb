# Changelog

## 0.1.0

First stable release, published to pub.dev. Targets `kmdb` `^0.1.0`.

Provides `PdfTextExtractor`, a `VaultTextExtractor` for `application/pdf` vault
blobs, wrapping `betto_pdfium` for native plain-text extraction. Optional,
opt-in; native platforms only.

### Requirements

- Dart SDK `^3.13.0`.
