# Friction logs

Completed copies of [`../friction_log_template.md`](../friction_log_template.md)
live here, one file per validation run, named
`YYYY-MM-DD_run-description.md` (e.g. `2026-09-10_run-1.md`).

Each file is a dated snapshot of what someone (or some agent) hit while
following the [Integration Guide](../README.md) — never edit the template
itself; always start from a fresh copy.
